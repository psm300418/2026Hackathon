## 1. 디자인 방향

SkinData는 피부 기록과 제품 사용 데이터를 빠르게 남기는 도구다. 화면은 장식보다 입력의 선명함, 넓은 여백, 명확한 버튼 대비를 우선한다.

핵심 키워드:

- White
- Clean
- Quiet
- Practical
- Mobile first

화면은 기본적으로 흰색 배경을 사용한다. 주요 CTA만 연한 민트색으로 강조하고, 텍스트는 검정에 가깝게 표시한다. 버튼 글자가 흐릿하게 보이면 안 되며, 비활성 상태가 아니라면 주요 버튼 텍스트는 항상 `#121212`를 사용한다.

## 2. Color

| 토큰 | Hex | 용도 |
| --- | --- | --- |
| `Ink` | `#121212` | 제목, 본문, 활성 버튼 텍스트 |
| `Muted` | `#B3B3B3` | 비활성 아이콘, placeholder, 보조 라벨 |
| `Line` | `#EFEFEF` | 구분선, 약한 카드 배경, 비활성 버튼 |
| `Mint` | `#EBFBFC` | 주요 CTA 배경, 선택된 약한 강조 |
| `Surface` | `#FFFFFF` | 기본 화면, 카드, 입력 배경 |

사용 규칙:

- 기본 배경은 `Surface`다.
- 주요 CTA는 `Mint` 배경과 `Ink` 텍스트를 사용한다.
- 보조 텍스트는 `Muted`만 사용하되, 긴 문장에는 너무 흐려지지 않도록 `#6F6F6F` 수준을 사용한다.
- 오류나 경고는 강한 빨강을 넓게 쓰지 않고 짧은 문장과 재시도 버튼으로 처리한다.

## 3. Typography

Android 기본 시스템 폰트를 사용한다. 추후 폰트를 추가한다면 `Pretendard`를 우선 검토한다.

| 역할 | 크기 | 굵기 | 용도 |
| --- | ---: | ---: | --- |
| `ScreenTitle` | 20sp | 700 | 로그인, 초기 설정, 주요 화면 제목 |
| `SectionTitle` | 16sp | 700 | 카드 또는 입력 섹션 제목 |
| `Body` | 14sp | 400 | 일반 본문, 리스트 텍스트 |
| `BodyStrong` | 14sp | 600 | 버튼, 강조 문장 |
| `Caption` | 11sp-12sp | 400 | placeholder, 보조 설명 |
| `NavLabel` | 10sp | 500 | 하단 탭 라벨 |

문장 배치:

- 로그인/회원가입/초기 설정 화면은 큰 제목을 좌측 정렬한다.
- 제품/기록/분석/설정 화면은 상단 영역 아래에 콘텐츠를 바로 배치한다.
- 화면 안 설명 문구는 짧게 유지하고, 기능 사용법을 길게 설명하지 않는다.

## 4. Layout

| 항목 | 값 |
| --- | ---: |
| 화면 좌우 여백 | 20dp |
| 상단 상태바 이후 첫 콘텐츠 여백 | 44dp-56dp |
| 섹션 간격 | 24dp |
| 카드 내부 여백 | 16dp |
| 입력/버튼 높이 | 38dp-44dp |
| 하단 CTA 좌우 여백 | 20dp |
| 하단 CTA와 바닥 간격 | 28dp |
| 하단 내비게이션 높이 | 60dp |

레이아웃 원칙:

- 한 화면에 하나의 핵심 행동을 둔다.
- 입력 폼은 얇은 테두리와 흰 배경으로 정리한다.
- 카드가 필요한 제품/분석/설정 영역만 8dp 이하 radius의 얇은 테두리 카드로 표시한다.
- 카드 안에 카드를 중첩하지 않는다.

## 5. Components

### Primary Button

- 배경: `Mint`
- 텍스트: `Ink`, 14sp, 600 이상
- 높이: 38dp-44dp
- radius: 6dp-8dp
- disabled: `Line` 배경, `Muted` 텍스트

### Text Field

- 배경: `Surface`
- 테두리: `#D8D8D8` 또는 `Line`
- radius: 6dp
- placeholder: `Muted`
- 텍스트: `Ink`

### Choice Chip

- 기본: 흰 배경, `#D8D8D8` 테두리, `Ink` 텍스트
- 선택: `Mint` 배경, `Ink` 텍스트
- 문구가 길면 칩 폭을 늘리거나 다음 줄로 배치한다.

### Bottom Navigation

- 배경: `Surface`
- 상단 구분선: `Line`
- 활성: `Ink`
- 비활성: `Muted`
- 탭은 아이콘과 라벨을 함께 표시한다.
- 탭: `제품`, `기록`, `분석`, `설정`
- 홈 탭은 MVP 핵심 흐름에 직접 연결되는 기능이 없으므로 두지 않는다.

### Simple Card

- 배경: `Surface`
- 테두리: `Line`
- radius: 6dp-8dp
- 그림자 없음
- 반복되지 않는 작은 정보 묶음에만 사용한다.

## 6. 화면별 기준

### 시작/로그인/회원가입

- 시작 화면은 중앙 문구와 하단 CTA만 둔다.
- 로그인 화면은 상단 뒤로가기, 중앙 제목, 이메일/비밀번호 입력, 로그인 CTA 순서로 구성한다.
- 회원가입은 한 단계에 너무 많은 입력을 넣지 않고, 하단 CTA를 고정한다.

### 초기 설정

- 피부 프로필, 생활 루틴, 현재 사용 제품을 단계별로 받는다.
- 선택지는 둥근 칩으로 배치하되 문구가 눌리는 영역 전체가 선택 가능해야 한다.
- 사용자가 이미 아는 피부 분류는 직접 선택하고, 모르는 분류만 설문으로 확인한다.
- 다음 설문으로 이동하면 스크롤 위치는 항상 화면 맨 위로 돌아간다.
- 얼굴 사진, 제품 이미지가 없는 화면도 충분한 여백과 얇은 입력 경계로 정리한다.

### 제품

- 이전에 사용해본 제품 등록과 공용 제품 DB 검색은 제품 탭에서 진행한다.
- 제품 검색, 직접 등록, 내 제품 목록 확인은 같은 탭 안에서 이어지게 구성한다.
- 설정 탭에는 제품 관리 기능을 두지 않는다.

### 기록

- 오늘 기록은 하루 1개다.
- 오늘 사용 제품, 수면 시간, 외출 시간, 얼굴 사진 선택 영역을 한 흐름으로 입력한다.
- 제품 프리셋은 빠른 적용 선택지로 제공한다.
- 제품 검색 후 선택하면 내 제품 목록에 추가하고 오늘 사용 제품에 바로 포함한다.

### 리포트

- 분석 기록 목록과 새 분석 CTA를 분리한다.
- 분석 결과는 의심 성분과 근거를 보여주되 원인 확정이나 진단처럼 표현하지 않는다.
- 데이터 부족 상태는 부족한 기록 종류를 짧게 안내한다.

### 설정

- 리스트형 설정 화면으로 구성한다.
- 각 행은 좌측 라벨, 우측 chevron만 둔다.
- 그룹 사이에는 `Line` 색상의 넓은 구분 밴드를 사용할 수 있다.
- 알림은 현재 핵심 기능에서 제외하고 추가 기능으로 분리한다.

- 지역 설정, 기록 알림, 로그아웃처럼 계정 또는 앱 사용 환경에 관한 항목만 둔다.
- 지역 설정은 먼저 도/특별시/광역시/특별자치시/특별자치도를 선택하고, 이후 해당 지역의 시/군/구를 선택한다.
- 지역 목록은 전국 도 단위와 각 도에 속한 시/군/구를 빠짐없이 제공한다.

## 7. Accessibility

- 주요 터치 영역은 최소 40dp 이상을 유지한다.
- 버튼 텍스트는 흐릿하게 보이지 않게 `Ink` 또는 충분한 대비 색을 사용한다.
- 선택 상태는 색상만으로 표현하지 않고 테두리, 배경, 선택 라디오 상태를 함께 사용한다.
- 한국어 긴 라벨은 좁은 버튼 3개에 억지로 넣지 않고 세로 배치하거나 줄바꿈을 허용한다.

## 8. Compose 적용

현재 MVP 토큰은 다음 기준으로 맞춘다.

```text
SkinColors.Ink = #121212
SkinColors.Muted = #B3B3B3
SkinColors.SurfaceSoft = #EFEFEF
SkinColors.PrimaryOlive = #EBFBFC
SkinColors.Surface = #FFFFFF
SkinRadius.Card = 8dp
SkinRadius.Button = 6dp
```

기존 이름은 코드 변경 범위를 줄이기 위해 유지하되, 색상 의미는 이 문서의 새 기준을 따른다. 신규 화면을 만들 때는 색상 값을 직접 박지 말고 디자인 토큰을 우선 사용한다.
