# 바우만 피부타입 설문지 — 사용자 응답용 재구성본

> 이 문서는 공개 자료를 바탕으로 **사용자가 실제로 답하기 쉬운 한국어 설문 어투로 재구성한 비공식 버전**입니다.  
> Baumann Skin Type Indicator(BSTI) 공식 설문 원문을 그대로 복제한 것이 아니며, 실제 의료·상업 서비스에 사용할 경우 공식 판본 및 이용 권한을 별도로 확인해야 합니다.

## 설문 안내

아래 질문에는 **지금의 피부 상태뿐 아니라 평소 반복적으로 나타나는 피부 특성**을 기준으로 답해주세요.

- 특별한 날의 일시적인 피부 상태보다는 평소 상태를 기준으로 선택해주세요.

- 총 4개 영역을 통해 피부 타입을 확인합니다.

# 개발자용 점수 계산 참고

일반 문항의 기본 선택지 배점:

```text
A = 1점
B = 2점

D = 4점

```

단, 실제 구현 전에는 사용할 BSTI 판본의 정식 배점과 반드시 대조해야 합니다.

## O/D 판정

문항:

```text
Q1 ~ Q11
```

대표 판정 기준:

```text
11 ~ 26점 → D (Dry)
27 ~ 44점 → O (Oily)
```

세분화:

```text
11 ~ 16 → 매우 건조
17 ~ 26 → 약간 건조
27 ~ 33 → 약간 지성
34 ~ 44 → 매우 지성
```

## S/R 판정

문항:

```text
Q12 ~ Q29
```

대표 판정 기준:

```text
29점 이하 → R (Resistant)
30점 이상 → S (Sensitive)
```

세분화:

```text
17 ~ 24 → 매우 저항성
25 ~ 29 → 약간 저항성
30 ~ 33 → 약간 민감성
34 이상 → 매우 민감성
```

추가 가산점으로 공개된 규칙:

```text
피부과 전문의에게 여드름·주사·접촉피부염·습진 등을 진단받음 → +5점

```

# 최종 피부타입 조합

4개 영역에서 나온 문자를 순서대로 조합합니다.

```text
O 또는 D
+
S 또는 R
+
P 또는 N
+
W 또는 T
```

예:

```text
O + S + N + T = OSNT
```

총 16가지 조합이 가능합니다.

```text
OSPW  OSPT  OSNW  OSNT
ORPW  ORPT  ORNW  ORNT
DSPW  DSPT  DSNW  DSNT
DRPW  DRPT  DRNW  DRNT
```

# 서비스 구현 시 권장 구조

사용자에게는 다음 정도만 보여주는 것이 자연스럽습니다.

```text
질문
↓
선택지
↓
다음 질문
```

점수는 화면에 표시하지 않고 내부적으로만 계산합니다.

예시:

```yaml
id: OD_01
question: "세안 후 아무것도 바르지 않고 2~3시간이 지나면 피부가 어떤가요?"
options:
  - label: "매우 건조하고 각질이 일어나거나 거칠게 느껴져요."
    score: 1
  - label: "피부가 당기거나 약간 건조해요."
    score: 2
  - label: "특별히 건조하지도, 번들거리지도 않아요."
    score: 3
  - label: "이마나 볼이 눈에 띄게 번들거려요."
    score: 4
```

권장 데이터 구분:

```text
questionnaire_version
dimension
question_id
question_text
option_id
option_text
score
special_rule
```

이렇게 분리하면 설문 문구를 수정하더라도 판정 로직을 독립적으로 관리하기 쉽습니다.
