# 국내 스킨케어 제품 전성분 Seed Data — 국내 공식 제품명 확인판 97종

> 수집·확인일: 2026-08-16  
> 목적: 개인 피부 데이터 서비스의 초기 `Product` / `ProductIngredient` DB 구축을 위한 Seed 조사자료  
> 범위: 한국 스킨케어 브랜드의 대표·인기 라인 중심 97종  
> 출처 원칙: **브랜드 공식 웹사이트에서 제품별 Ingredients / Full Ingredients가 직접 공개된 자료만 사용**
> 제품명 표기 원칙: **국내 공식몰 또는 브랜드의 국내 공식 자료에서 확인되는 한국어 상품명만 수록했다. 국내 공식 한국어 상품명을 확인하지 못한 제품은 제외했다. 전성분은 기존 한국어 번역·음역본이므로 MFDS 표준명과 최종 대조가 필요하다.**
> 국내 공식명 확인 상태: **97종 확인 / 미확인 제품 제외**

## 데이터 사용 전 주의사항

- 이 문서는 초기 DB 구축용 조사자료이며 의학적·규제적 판단의 원본 자료가 아니다.
- 동일한 제품명이라도 **국가, 용량, 리뉴얼 시점, 제조 시기**에 따라 처방과 전성분이 달라질 수 있다.
- 일부 출처는 브랜드의 미국/글로벌 공식몰이다. 따라서 한국에서 실제 유통되는 동일명 제품과 처방이 완전히 같다고 가정하면 안 된다.
- 운영 DB에는 `source_url`, `source_checked_at`, `region`, `formula_version` 또는 이에 준하는 버전 정보를 함께 저장하는 것을 권장한다.
- 전성분은 공식 페이지의 기재 순서를 최대한 유지했다. 다만 웹 페이지 표기의 명백한 공백·철자 파싱 오류는 읽기 가능한 형태로 정리한 항목이 있다.
- 실제 분석에 사용하기 전에는 MFDS 화장품 원료성분정보 등 별도의 Ingredient Master와 대조하여 **표준명·이명·INCI 명칭을 정규화**하는 것이 좋다.
- 이 목록은 '국내 판매량 상위 100위'를 의미하지 않는다. 대중적으로 알려진 브랜드의 대표 제품, 베스트셀러/리뷰가 많은 라인, 장기 피부 기록에 활용도가 높은 기초화장품을 우선 선정한 Seed Dataset이다.
- 공식 페이지 안에서 서로 다른 전성분 표기가 충돌하는 등 출처 일관성을 확인하기 어려운 제품은 제외했다.
- 본 문서의 한국어 성분명은 **가독성을 위한 번역·음역**이다. 실제 서비스 DB의 표준 성분 ID를 생성할 때는 식약처(MFDS) 원료성분정보와 대조해 표준화한다.

## 초기 DB 반영 권장 구조

제품과 전성분을 단일 문자열로만 저장하기보다, 제품·처방 버전·성분을 분리하면 리뉴얼이나 국가별 처방 차이를 관리하기 쉽다.

```text
Product
- id
- brand
- name
- category

ProductFormula
- id
- productId
- region
- sourceUrl
- sourceCheckedAt
- formulaVersion
- rawIngredientText

ProductIngredient
- productFormulaId
- ingredientId
- ingredientOrder

Ingredient
- id
- standardNameKo
- standardNameEn
- aliases
- casNumber
```

운영 환경에서는 공식 페이지의 원문 전성분(`rawIngredientText`)도 함께 보존해 두면 향후 정규화 규칙이 바뀌었을 때 다시 처리하기 쉽다.
